# 日常任务模板库

## 背景

当前 35 个 cron 任务各有各的写法：有的指令太长（2000+字），有的缺判断层，有的不写数据日期和来源，有的卡片格式不一致。需要一个统一的模板标准，让所有任务质量一致，且写新任务不用从零构思。

## 模板金字塔

```
                ┌──────────┐
                │ 北极星目标 │  ← 每任务开头必带
                └────┬─────┘
                     ↓
         ┌───────────────────┐
         │   固定四步流水线    │
         ├───────────────────┤
         │ ① 前置校验        │  ← 数据源存在？cookie有效？
         │ ② 数据采集/分析    │  ← 核心执行
         │ ③ 判断层输出       │  ← 🎯💡⚠️ 三件套
         │ ④ 卡片发送+审计    │  ← 标准卡片格式
         └───────────────────┘
```

## 任务分类模板

### A类：数据采集型（抖音指数/客流/小红书灵犀）
```
## [北极星目标]

### 步骤
1. 前置校验：cookie/文件/代理是否就绪
2. 执行脚本采集数据
3. 解析输出，提取关键变化（环比/同比/异常值）
4. 判断层：🎯关键发现 💡建议 ⚠️风险
5. 标准卡片→飞书群
```

### B类：分析洞察型（竞品关键词/文旅情报/爆款拆解）
```
## [北极星目标]

### 步骤
1. 搜索/获取原始信息（限轮次）
2. 筛选最有价值的1-2条信息
3. 判断层：🎯影响等级 💡建议动作 ⏰执行窗口 ⚠️不做的代价
4. 标准卡片→飞书群
```

### C类：汇总复盘型（每日复盘/效果归因）
```
## [北极星目标]

### 步骤
1. 提取今日核心任务执行状态
2. 提炼最值得站长知道的1-2条
3. 判断层：🎯最大发现 💡明日最该做 ⚠️风险
4. 标准卡片→飞书群
```

## 标准卡片格式

```
## 📌 标题：含日期和任务名

| 指标 | 数值 | 变化 |
|------|------|------|

**判断层：**
- 🎯 **关键发现**：一句话
- 💡 **建议动作**：D1行动+执行时间
- ⚠️ **风险**：一句话
- ⏰ **数据日期**：YYYY-MM-DD
- 📍 **数据来源**：抖音指数/小红书灵犀/...
```

## 判断层基础三件套（必出）

每个任务输出必须包含以下三项，否则判定为不完整：

| 标记 | 名称 | 说明 |
|------|------|------|
| 🎯 | 关键发现 | 一个数字或事实，站长不知道的 |
| 💡 | 建议动作 | D1做什么，什么时候做 |
| ⚠️ | 风险 | 不做会怎样，或有什么隐患 |

## 指令长度规范

| 类型 | 建议长度 | 最大长度 |
|------|---------|---------|
| 指令正文 | 400-600字 | 800字 |
| 步骤数 | 3-5步 | 6步 |
| 搜索轮次 | B类任务 | 2轮 |
| 判断层条目 | 3-5条 | 6条 |

## 使用方式

当需要编写或修改一个cron任务时：
1. 识别任务属于 A/B/C 哪一类
2. 套用对应模板，填空
3. 确保判断层三件套俱全
4. 确认指令不超过800字

## 审计项

✅ 北极星目标是否标注
✅ 数据日期和来源是否标注
✅ 判断层三件套是否完备
✅ 指令是否超过800字（超则截断）
✅ 卡片格式是否符合标准
