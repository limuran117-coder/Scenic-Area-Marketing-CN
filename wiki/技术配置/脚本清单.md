## douyin_index_v9.py

**位置：** `~/.openclaw/workspace/scripts/douyin_index_v9.py`

**⚠ 文件名与实际版本不一致：** 内部声明为 **v10**（2026-05-16更新），文件名仍为v9

**功能：** 抖音创作者后台订阅数据采集（8个竞品景区）

**采集URL（v10更新）：** `https://creator.douyin.com/creator-micro/creator-count/arithmetic-index`

**v10变更（2026-05-16）：**
1. URL变更：`arithmetic-index`（原 `my-subscript?source=creator`）
2. 增加Cookie预检机制
3. 所有操作间隔调大到5-8秒+随机抖动(-30%~+30%)
4. 增加人类行为模拟(鼠标随机移动)
5. Cookie过期时生成错误标记，避免静默失败

**采集逻辑：**
1. 连接专属浏览器 CDP (18800)
2. Cookie预检 → 导航到指数页
3. 检测页面数据日期，若非今日 → `page.reload()` 等待8秒
4. 滚动触发懒加载 → 读取页面文本
5. 正则解析景区名+搜索指数+综合指数
6. 输出JSON到 `/tmp/crawl_data.json`
7. 关闭Page，保留Browser

**输出格式：**
```json
{
  "date": "2026-04-22",
  "crawled_at": "2026-04-22T10:30:00",
  "competitors": [
    {"name": "万岁山武侠城", "search": 47390, "synth": 24952},
    ...
  ]
}
```
