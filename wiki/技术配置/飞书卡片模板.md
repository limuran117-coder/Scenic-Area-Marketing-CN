### 格式要点
| 要素 | 规范 |
|:----|:----|
| 卡片类型 | interactive（不可用 text/post） |
| header.title | tag=plain_text, content=标题文字 |
| header.template | orange-数据 / purple-分析 / red-预警 |
| 表格语法 | 标准 markdown `|` 管道符，放 markdown 元素 content 中 |
| 分割线 | `{"tag": "hr"}` |
| emoji | ✅ 所有 markdown 元素支持 |
| 排序 | 按综合指数从高到低 |
| 异动 | 🔺 标注在数值旁 |
