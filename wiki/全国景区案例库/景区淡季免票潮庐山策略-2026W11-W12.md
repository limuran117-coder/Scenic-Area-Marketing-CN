# 景区免票潮：庐山"淡季不淡"的商业逻辑

> 全国上百家景区 | 2026年春季 | 央视网/多家媒体报道

---

## 案例速览

| 项目 | 内容 |
|------|------|
| 💡 **打法** | **淡季免票→流量暴增→二消转化** — 景区在传统淡季（3月/11月）推出免票或低价策略，以失去门票收入换取流量井喷，通过索道/观光车/餐饮/文创等二消弥补收入 |
| 📊 **数据** | 庐山：半月游客109.77万人次(+130.73%)、日均闸机7.4万人次、索道日均8000人、观光车日均10000人；搜索量周环比+156% |
| 🏷️ **标签** | #淡季激活 #免票策略 #门票经济转型 #二消转化 #流量杠杆 |

## 详细拆解

### 1. 免票模式类型

| 类型 | 典型案例 | 效果 |
|------|---------|------|
| **全月免票** | 庐山3月全月免票 | 半月109.77万人次(+130.73%) |
| **生肖免票** | 太白山/庐山/赛里木湖"属马游客免票" | 精准筛选客群，社交传播+ |
| **地域免票** | 多地"对口帮扶省市免票" | 定向引流+政府关系 |
| **早鸟免票** | 部分景区"前多少名免票" | 制造稀缺感，倒逼早到 |
| **年票/季票** | 多景区"一票全年通" | 刺激复购，锚定长期用户 |

### 2. 商业逻辑拆解

```
免票 → 入园人次暴涨 → 二消大幅增加（索道+观光车+餐饮+文创） → 总收入不降反升
```

| 收入项 | 传统模式（有门票） | 免票模式 |
|--------|-----------------|---------|
| 门票收入 | 100元/人×10万=1000万 | 0元 |
| 索道收入 | 50元/人×6万=300万 | 50元/人×15万=750万 |
| 观光车收入 | 30元/人×4万=120万 | 30元/人×12万=360万 |
| 餐饮/文创 | 人均50×10万=500万 | 人均80×20万=1600万 |
| **总计** | **1920万** | **2710万（+41%）** |

*注：上述为简化推演模型，实际庐山二消结构更复杂*

### 3. 关键成功条件

- **必须内部交通需求**：山岳型景区必须坐索道/观光车上山，二消天然刚需
- **产品力够**：免票带来"低廉门槛"，但能让游客留下吃饭/购物的核心还是景区体验本身
- **人流分散**：免票需配合预约制，防止超出承载上限导致体验崩塌

## 适用场景

| 维度 | 分析 |
|------|------|
| ✅ **适用场景** | 淡季客流断崖式下跌（下滑40-60%）且有内部消费场景的景区 |
| 💥 **触发条件** | ①连续2周入园量低于承载量的30% ②周边竞品开始降价促销 ③景区内商家/合作方面临经营压力 |
| 🔁 **可复制动作** | ①评估景区内部二消容量：有无索道/餐饮/文创等可覆盖门票损失？②测算"免票盈亏平衡点"：需增长多少人次才能保本？③设计预约分流机制，防止体验次生灾害 ④提前准备二消产品（如庐山观光车+索道联票） |
| 🎬 **电影小镇适配度** | ⭐⭐ **部分适配**（但有核心差异）。电影小镇不同于山岳景区：①没有索道/观光车等"强制二消"场景，免票后收入补偿难度大 ②主题公园单一免票难以持续吸引复购 ③但可尝试"淡季指定日免票"或"生肖免票"限时限量模式 |

---

## ⚠️ 不建议照搬

- 山岳型景区与主题公园收入模型不同，主题公园最高效的二消是餐饮+零售+付费体验
- 电影小镇更适合 **"特定人群免票"** （如河南身份证/学生/银发等）+门票内包含部分二消券
- 免票可能引发"低价即低质"的消费者心理，需搭配增值服务感知

---

## 电影小镇实操建议

1. **参考"生肖免票"**：每季度选一个群体（属相/姓氏/职业）做指定日免票，制造话题
2. **淡季"门票含券"**：门票不打折，但含20元餐饮券+10元文创券，实际让利但保持价格锚点
3. **"一张门票用两次"**：淡季票有效期1个月可随时复游，类似龙潭大峡谷模式（已有案例[[龙潭大峡谷一张门票用一年真诚逆袭-2026W22]]）
4. **异业免票置换**：凭电影小镇周边商场/酒店消费小票免门票入场，商场方承担补贴
