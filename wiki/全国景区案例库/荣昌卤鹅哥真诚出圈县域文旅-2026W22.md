## 打法拆解

### 1. 美食IP引爆 — 低成本出圈

- **触发机制：** 地方特色美食（荣昌卤鹅）通过短视频/直播疯狂传播
- **核心人物：** "卤鹅哥" — 草根美食博主的真实感内容
- **传播路径：** 地方美食→短视频爆款→全网热议→线下打卡

### 2. "宠客"措施 — 全城服务闭环

荣昌打出了一套**极致的"宠客"服务组合拳**：

| 措施 | 说明 |
|------|------|
| 景区免门票 | 所有收费景区门票全免 |
| 公交免费 | 全城公交车免费乘坐 |
| 停车免费 | 所有政府机关/事业单位/公共市政停车场免费 |
| 政府食堂对外开放 | 游客可进政府食堂吃饭（1200斤大米/天） |
| 限流不涨价 | 保证体验不因客流下降 |

### 3. 多县域跟进 — 成为新标配

湖北赤壁、浙江衢州、安徽黟县、江苏东海等地政府食堂也在五一"开门迎客"，江苏东海县50家单位提供3600+个免费停车位。

## 适用场景

| 维度 | 分析 |
|------|------|
| **适用场景** | 中小城市/县域级景区的"真诚出圈"策略；非节假日日常引流 |
| **触发条件** | ①有极具地方特色的美食/产品可做内容引爆 ②地方政府愿意开放公共服务资源③有一定的接待基础（住宿/交通/停车） |
| **可复制动作** | ①挖掘地方特色美食/产品作为**内容引爆点** ②政府主导"宠客"措施（免票/免费停车/食堂开放）③借势热点在全网铺UGC内容 ④联动本地商家做吃住行闭环 |
| **⚠️ 前置条件** | 需要地方政府主导协调多部门资源，非景区单方可以完成；适合县级行政区而非单一景区 |
| **电影小镇适配度** | ⭐⭐⭐ **部分适配**。电影小镇可借势：①联合中牟县政府推出"宠客"礼包（门票优惠+停放便利+周边景区联动）②发掘园区特色美食做内容引爆点 ③但政府开放食堂等需要更高层面的协调，非景区能单干 |

---

## 核心启示

1. **真诚出圈的杠杆极高：** 政府食堂开放的成本远低于投放广告，但产生的社会讨论度和品牌好感度不可估量
2. **美食是最低成本的内容引爆点：** 相比大制作内容，一个地方特色美食的短视频引爆门槛最低
3. **"宠客"正在成为新标配：** 多县城五一跟进政府食堂开放，证明这套打法正在规模化

## ⚠️ 不建议照搬

- 荣昌出圈有"卤鹅哥"的偶发性和不可复制性
- 政府食堂开放、全城免费等需要地方政府一把手拍板，景区无权决定
- 案例核心价值在**真诚出圈的方法论**而非具体动作
