# ⚠️ 不建议照搬清单：IP 过度依赖 + 噱头衰减（W24更新）

> **摘要：** 电影小镇可调用营销招法库的"反面案例墙"——把过去 1-2 年文旅行业"一时热闹但不可复用"的案例集中归类。每个反面案例必须标注"为什么火"、"为什么不可复用"、"电影小镇应该避开的具体动作"。

---

## 入库标准

满足以下任一条件即入库本清单：

1. **IP 过度依赖型**——单一 IP/节目/角色占客流量 > 50%
2. **噱头速朽型**——3 个月内热度衰减 > 80%
3. **商业化翻车型**——因过度商业化导致口碑暴跌
4. **政策套利型**——依赖政策窗口期红利，窗口关闭即失效
5. **执行力陷阱型**——招法要求极高人力/资源，普通景区无法复制

## 案例 1｜济南夏雨荷 IP 过度商业化翻车

| 维度 | 内容 |
|------|------|
| **触发** | 2024年因"大明湖夏雨荷"IP 火爆 |
| **为什么火** | 怀旧情绪+短视频助推，3 周内搜索指数 +450% |
| **为什么翻车** | 短期内商业化过载——夏雨荷主题餐饮、文创、换装、表演全部上线，价格虚高 |
| **数据** | 半年内差评率从 3% 升至 28%，复购率从 25% 跌至 8% |
| **电影小镇警示** | **单一 IP 商业化进度必须严格控制**——每季度新增 IP 商业 SKU 不超过 3 个 |
| **关联案例** | [[济南夏雨荷IP过度商业化翻车-2026W20]] |

## 案例 4｜"集赞换门票"薅羊毛模式

| 维度 | 内容 |
|------|------|
| **触发** | 2024年部分景区推出"集 100 赞换免费门票" |
| **短期数据** | 拉新数据亮眼，单周拉新 10 万+ |
| **为什么不可复用** | 吸引来的全是价格敏感型用户，二消转化率 < 3%，三个月后差评率 40%+ |
| **电影小镇警示** | **不搞"零成本获客"模式**——目标用户应该是中高消费力游客，不是薅羊毛用户 |

## 案例 5｜"全网最低价"恶性价格战

| 维度 | 内容 |
|------|------|
| **触发** | 2024-2025 多地景区推出 9.9 元/19.9 元"超低价门票" |
| **为什么短期有效** | 搜索指数瞬间拉升 500%+ |
| **为什么不可复用** | 拉来的全是"不会再来"的低价用户；品牌锚定下沉；后续涨价 3 倍也拉不回原价 |
| **电影小镇警示** | **不参与纯低价竞争**——所有降价必须"结构化"（年卡/多次卡/工作日票）而非"绝对降价" |
| **替代方案** | 招法 4"门票结构性降价+权益叠加"（[[招法组合4-爆款公式3组合-2026W24]]） |

## 案例 6｜"门票+强制二消套餐"

## 总体原则（电影小镇应该建立的"营销红线"）

1. **不押注单一 IP**——单 IP 流量占比控制在 30% 以内
2. **不参与纯低价竞争**——所有降价结构化、年卡化、权益化
3. **不走擦边/低俗路线**——长期 LTV 优先
4. **不强制二消绑定**——用内容驱动自发达成
5. **不搞薅羊毛获客**——目标用户质量优先
6. **不一次性大投入**——内容迭代走"小步快跑"路线
