## 一、项目概述

### 1.1 要解决什么问题

现有#5全国爆款拆解仅分析**互动数据**（点赞/收藏/评论数），但**不知道内容为什么火**：

| 现有能力(#5) | 缺什么 | 目标(#16) |
|:------------|:-------|:----------|
| 知道这个视频/笔记🔥 | 为什么🔥→画面/标题/结构 | 拆出火的**规律** |
| 知道互动数字 | 视觉风格如何影响互动 | 画面/封面分析 |
| 知道博主类型 | 标题怎么做抓住了用户 | 标题公式提取 |
| 有什么建议 | 评论区真实情绪是什么 | 评论情绪归因 |

### 1.2 双平台覆盖

| 平台 | 内容类型 | 分析难度 | 优先级 |
|:----|:---------|:--------:|:------:|
| 抖音 | 短视频 | 🟠 中（需帧提取+语音转文字） | P0 |
| 小红书 | 图文笔记 | 🟢 低（封面图+正文结构分析） | P0 |
| 小红书 | 视频笔记 | 🟡 中（帧提取+字幕） | P1 |

## 二、技术架构

```
采集层（现有CDP+Playwright，复用#4的方案）
     │
     ├── 抖音竞品视频列表  ──→  视频下载/URL采集
     ├── 小红书竞品笔记    ──→  图文采集（封面+正文）
     └── 小红书竞品视频    ──→  视频URL采集
                    │
                    ▼
    分析层（新增能力）
     │
     ├── V1·文字增强（2周）
     │   ├── 标题公式提取  → Gemini读标题文本
     │   ├── 正文结构分析  → Gemini读笔记正文
     │   └── 评论情绪归因  → Gemini读评论TOP100
     │
     └── V2·视觉语义（~1月）
         ├── 抖音视频      → 帧提取(3s/帧)→场景识别
         ├── 小红书封面    → 图片分析→风格归因
         └── 字幕/OCR      → Gemini语音转文字/OCR
                    │
                    ▼
    输出层（复用#10+#12的方案）
     │
     ├── 结构化分析报告   → 飞书卡片(#12)
     ├── 可复制建议       → 沉淀到concepts/内容爆款规律(#10)
     └── 案例库更新       → 全国景区案例库/W-m.md(#5)
```

## 三、工具选型方案

### 3.1 核心AI选型（二选一）

| 对比项 | Gemini | MiniMax video |
|:-------|:-------|:--------------|
| 多模态能力 | ✅ 原生2M上下文+视频理解 | ⚠️ 需Hailuo Max计划 |
| 视频帧分析 | ✅ API直接处理 | ❌ 仅限文字/图片 |
| 图片分析 | ✅ 强 | ✅ 基础能力 |
| 语音转文字 | ✅ | ⚠️ speech功能可用 |
| 长上下文 | ✅ 2M tokens | ❌ 上下文较短 |
| 当前可用性 | ⚠️ 需要API key | ⚠️ video需升级 |
| 成本 | 按token计费 | 按次数计费 |

**推荐：V1用Gemini（现成能力），V2评估Gemini是否能cover，不行再上MiniMax video**

### 3.2 采集层改动

小红书图文采集：**现有#2灵犀后台+T6探索页已可获取笔记列表和正文**，只需增加封面图URL采集。
抖音视频采集：**现有CDP+Playwright已获取视频链接**，需要增加视频元数据（字幕、时长）。

**基本不需要新采集脚本，在现有脚本上扩展即可。**

## 四、两阶段实施路径

### V1：文字增强（预估2周）

| 周 | 任务 | 产出 |
|:-:|:-----|:-----|
| W1 | 采集侧：扩展小红书笔记采集（封面URL+正文全文+标题+标签+TOP100评论） | 扩展后的#2采集脚本 |
| W1 | 采集侧：扩展抖音视频采集（标题+描述+TOP100评论+博主信息） | 扩展后的#4采集脚本 |
| W2 | 分析侧：Gemini prompt设计（标题公式/结构分析/情绪归因/可复制建议） | prompt模板（SOP） |
| W2 | 输出侧：结构化报告模板+飞书卡片模板 | 卡片模板 |
| W2 | 数据沉淀：整合到现有#5爆款拆解流程，增加视觉/语义维度 | 更新后的#5 SOP |

#### V1 Gemini prompt → 分析框架

```
[输入]
- 小红书标题：《XXX》 
- 正文：全文（含emoji、换行结构）
- 标签：#xxx #xxx
- 封面图URL：（V2再说）
- TOP100评论

[AI输出]
- 标题公式: [悬念/对比/情感/攻略/数字]
- 情绪锚点: [焦虑/向往/好奇/共鸣]
- 结构类型: [走心/攻略/测评/故事]
- 互动归因: 为什么这条🔥了
- 可复制建议: 电影小镇可以直接用的点
```

### V2：视觉语义（预估1月）

| 周 | 任务 | 产出 |
|:-:|:-----|:-----|
| W3 | Gemini多模态接入测试 | 验证视频帧分析+图片分析效果 |
| W3 | 封面图分析：色调/构图/文案排版/人物 | 封面特征提取脚本 |
| W4 | 视频帧提取方案：3s/帧→场景识别 | 视频帧提取脚本 |
| W4 | Gemini字幕提取+视频元数据 | 字幕+场景描述 |
| W5 | 整合分析：视觉+文字→综合报告 | V2升级版prompt |
| W6 | 稳定运行+效果验证 | 运行SOP |
