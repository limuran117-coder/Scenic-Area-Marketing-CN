## P0-1 · 毕业生免票活动上线

### 背景
- 6/15 已预警"今天内必须跟进"，跳票至 6/30（**第 15 天**）
- 高考毕业生窗口期：6/20-7/15（**剩余 15 天**）
- 竞品动作：清明上河园 6/9-6/30 高考学子免门票 19.9 元（**已截胡第一波**）
- 河南 17 市免票矩阵已成型（6/19 跟进预警）
- 全国 13 省+毕业季免票矩阵成型

### 需求规格

**目标**：抢回 6/20-7/15 毕业生窗口剩余流量

**建议方案**（请站长决策是否调整）：
| 维度 | 规格 |
|------|------|
| 免票对象 | 2026 届高考生/中考生（凭准考证 + 身份证） |
| 免票内容 | 建业电影小镇大门票（不含二消/夜游/联票） |
| 时间窗口 | 7/1-7/15（覆盖考生填报志愿+暑期前两周） |
| 配对产品 | 毕业生专属夜场半价 / 换装馆免费体验 / 老冰棍怀旧礼包 |
| 流量入口 | 抖音挑战赛 #毕业电影小镇 + 小红书 KOC 笔记 + 线下考点地推 |

**与竞品差异化**：
- 清明上河园只有免门票（19.9 元）
- 我们做"免门票 + 1 个记忆点"（老冰棍怀旧礼包，差异化"回到小时候"主题）

### 验收标准

| 维度 | 目标 |
|------|------|
| 上线时间 | **2026-07-01 09:00 前** |
| 抖音端 | 1 条主推视频 + 3 条 KOC 跟进，单条互动>1,000 |
| 小红书端 | 5 篇 KOC 笔记，搜索"建业电影小镇 毕业"进入前 3 篇 |
| 售票/检票系统 | 准考证识别 + 实名验证打通，**不能让人工识别** |
| 数据闭环 | 当日毕业生入园人数独立统计，进日报 |
| 转化率 | 7/1-7/15 期间毕业生引流 ≥ **5,000 人次** |

### 风险提示

- ⚠️ 端午窗口已失（6/20-6/30），剩余 15 天窗口被竞品多次截胡
- ⚠️ 准考证验证技术方案需 24h 内出（避免现场拥堵）
- ⚠️ 7/1-7/15 与方特 65 天夜场重叠，需在文案/视觉上差异化
- ⚠️ 与只有河南 6/21 夏至夜幻城（68 天持续）抢夜间客流，需提前 24h 蓄水
