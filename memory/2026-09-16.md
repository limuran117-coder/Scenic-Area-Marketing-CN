### 根因二：Chrome 152 CDP「浏览器级」命令被封
<!-- project: github.com/limuran117-coder/Scenic-Area-Marketing-CN -->
- 现象：`Browser.setDownloadBehavior: Browser context management is not supported`（Playwright）+ `Storage.getCookies → Browser context management is not supported`（原生 WS 连 **/json/version 的浏览器端点**）
- **定位突破（08:14 实测）**：同一 `Storage.getCookies` 改连 **page target 端点**（`/json/list` 里 type=page 的 `webSocketDebuggerUrl`）→ ✅ 正常返回 376 条
  → 结论：**Chrome 152 只封了 browser-level session 的这批命令，page-level 完全正常**
- 另实测：browser 端点上 `Browser.getVersion` / `Browser.setDownloadBehavior` / `Target.getBrowserContexts` **单发均 ✅**；`connect_over_cdp` 此刻也 ✅ 成功（contexts=1）
  → 说明 Playwright 失败属**间歇性**（与浏览器状态相关），非硬性不兼容
