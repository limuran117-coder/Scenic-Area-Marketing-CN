
## 21:00 Ontology Week 5 研究完成

### 主题：基础设施评估（Neo4j vs SQLite vs 纯JSON）

**关键发现：**
- SQLite 选定为核心存储：零配置 + Python 内置 + 性能足够
- Neo4j 评估结论：暂不引入（数据量 < 50MB，图查询优势体现不出，运维成本高）
- OWL/RDF/SPARQL 评估结论：永久不引入（操作型本体不需要语义推理）
- JSON-LD 评估结论：未来可加 @context 做互操作，当前不需要

**关键决策：**
- D-005：采用 SQLite 而非 Neo4j 作为核心存储
- D-006：JSON 文件保留作为 Git 快照层（adapter 双写）
- Week 6 原型：最小可行 Ontology Layer（SQLite store + query engine）
