# 2026-08-18 故障处理记录

## 🔧 08:50 心跳发现：今早8点一批cron失败（竞品内容动态4x/竞品关键词/竞品爆款）

**根因链**：
1. searxng 容器（docker :8888）代理配置错误：`HTTP_PROXY=http://127.0.0.1:7897`，但容器是 bridge 网络，127.0.0.1 指向容器自身 → 所有外部请求 Connection refused
2. 只有 baidu/bing 引擎启用，baidu 被 CAPTCHA 封（Suspended: CAPTCHA），bing 因代理不通全超时
3. → web_search 全返回 0 结果 → 依赖搜索的 cron（竞品爆款/竞品内容动态/竞品关键词）失败

**修复**：
1. 重建 searxng 容器：代理改 `host.docker.internal:7897`（容器内实测可通，bing 返回 200 + b_algo 结果）
2. 显式禁用不可达引擎：google cse / wikipedia / wikidata（国内不可达，避免每次超时拖慢）
3. settings.yml 已备份 `settings.yml.bak.20260818`

**验证**：搜索恢复 8-9 条结果，0 unresponsive 引擎 ✅

**教训**：
- Docker bridge 容器里 127.0.0.1 不是宿主机！代理/服务地址要用 host.docker.internal
- searxng 容器网络：`docker inspect searxng --format '{{.HostConfig.NetworkMode}}'` 是 bridge
- 容器代理配置在 env：`docker inspect searxng --format '{{json .Config.Env}}'`
- 重建命令参数已记录在本次处理中（env 代理 + -p 8888:8080 + settings.yml 挂载 + searxng_cache/searxng_etc 卷 + --restart unless-stopped）
