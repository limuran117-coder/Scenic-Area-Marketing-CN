# 飞书卡片格式规范

## 核心规则
JSON必须放`card`参数，不能放`message`参数

## 表格渲染铁律（2026-05-31验证）
- **表前分隔**：表格前必须用 `\n\n`（双换行=段落分隔），不能用 `<br/>`
- **行间换行**：表头行、分隔行、数据行之间用 `\n`（单换行）
- **表头可用⚠️**：表头列名含 `⚠️` 符号不影响渲染
- **禁止混用**：同一element内不要混 `<br/>` 和 `\n`——表格部分统一用 `\n`
- **正确示例**：
  ```
  "说明文字\n\n| 列1 | 列2 |\n|-----|-----|\n| 数据 | 数据 |"
  ```
- **错误示例**：
  ```
  "说明文字<br/><br/>| 列1 | 列2 |<br/>|-----|-----|"
  ```

## JSON格式
```json
{
  "schema": "2.0",
  "header": {"title": {"tag": "plain_text", "content": "标题"}, "template": "blue"},
  "body": {"elements": [{"tag": "markdown", "content": "内容"}]}
}
```

4. 关键洞察

## 数据业务含义
- 搜索指数 = 潜在游客主动搜索热度
- 综合指数 = 全网曝光综合热度
- 关联词 = 游客兴趣路径
- 人群画像 = 投放策略依据
- 涨跌 = 趋势信号
