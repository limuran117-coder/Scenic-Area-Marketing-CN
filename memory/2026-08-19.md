## 结论
**Graphiti 是唯一闭环可行项**：
- AutoResearch (~43.7K⭐): 需 GPU 训练，Mac 无 N 卡 ❌
- RAGFlow (~200K⭐): 重平台 16G 内存撑不住，与 chromadb 重复 ❌
- Unsloth: 仅 NVIDIA CUDA，Apple Silicon 不适配 ❌
- Milvus: chromadb 已覆盖现有量级 ❌
- **Graphiti: skill 已装但服务未跑，本地化改造后全链路跑通 ✅**

## 部署架构（零 OpenAI 依赖）
- LLM: DeepSeek deepseek-v4-flash（json_object 模式）
- Embedding: Ollama bge-m3（1024 维，本地）
- Reranker: stub 跳过（后续可升级）
- 存储: FalkorDB Docker（localhost:6379）
- 库: graphiti-core 0.29.3（/tmp/graphiti-venv）

## 关键踩坑（已解决）
1. **macOS 系统代理 127.0.0.1:7897 劫持 Python HTTP 客户端** → 本地请求全 502，curl/nc 正常。修复: `trust_env=False`。这是最隐蔽的坑，试遍所有 HTTP 参数才发现。
2. Ollama /v1/embeddings 兼容层问题 → 改用原生 /api/embed
3. graphiti-core API 变化: episode_body/reference_time/search 无 limit
4. group_id 即 FalkorDB 数据库名

## 经验沉淀（写入 MEMORY 级别）
- **本机任何 Python HTTP 客户端连 localhost 必须显式禁用代理**（trust_env=False / proxies=None），否则被 7897 抓站代理劫持返回 502
- Graphiti 本地化 = DeepSeek + Ollama bge-m3 + FalkorDB，官方 docker-compose 服务端硬编码 OpenAI，不可直接用
- **Graphiti 只建实体间关系的边**：写入前想清楚是关系型事实还是数值型数据，数值型别进图
- **16GB 机器 reranker 方案**：不要装 sentence-transformers 的 bge-reranker（2GB+）；用 Ollama bge-m3 embedding 做余弦重排（零新依赖）足够

## 14:00 灵犀「对比对象」功能探测结论（站长指示：实现不了就跳过）

**探测过程**：CDP 18800 打开 idea.xiaohongshu.com/idea/competitor/list → 新增对比对象弹窗（品牌集/产品集两种模式）→ 行业可选"出行旅游" → 品牌搜索 API 全部 total=0。

**关键证据**：

- 列表页「行业类目」下拉是 **disabled** 状态（`d-new-cascader__select disabled`）

**结论**：灵犀对比对象功能对景区行业暂不可用（品牌/SPU 库为空，可能需特殊权限或平台尚未开放景区类目）。**放弃该路径，不写代码实现。**

**替代方案**：竞品对比数据继续用自建采集链（xhs_daily_collector.py + adapter-xiaohongshu.py 已恢复 8/8 景区 + 灵犀首页 3 指标），不依赖灵犀对比对象功能。
