## [2026-09-20] 🔧 searxng 断档 32 天根治 —— 根因在 Docker daemon 层 <!-- project: github.com/limuran117-coder/Scenic-Area-Marketing-CN -->

- **根因（不是引擎被封）**：Docker Desktop 设置 `AutoStart = False` → 机器重启后 daemon 不跟随启动 → 容器整体消失 32 天
- **恢复路径**：`open -a Docker` 后容器靠 `restart: unless-stopped` **自动全部回归**，无需重建
- **第二层故障（引擎级）**：baidu CAPTCHA ／ bing parsing error ／ duckduckgo HTTP 连接失败 ／ quark 被 searxng 判 CAPTCHA 后 **Suspended**
- **第三层**：OpenClaw searxng 插件发的 query 与 curl 不同，曾返回 0 结果；quark 被拉黑期间 360search 也间歇返 0 → **引擎是间歇性的，连续测试会自己触发限流**（排查时宁可少测）
- **修复动作**：`~/.openclaw/searxng/settings.yml` 启用 360search / quark / chinaso / sogou / google；google+duckduckgo 走容器内已配好的 `host.docker.internal:7897` 代理（实测 200，是最稳两条腿）
- ⚠️ **坑（复现级）**：本机 curl/任何 HTTP 客户端连 `127.0.0.1:8888` **必须 `--noproxy '*'`**，否则被 7897 抓站代理劫持 → 返回 **HTTP 000**（容器明明 Up）
- **持久化**：改 `~/Library/Group Containers/group.com.docker/settings-store.json` 的 `AutoStart=true` —— **必须先 quit Docker Desktop 再改**，运行中改会被覆写
- ⚠️ 重启 Docker Desktop 后 daemon 曾一度无响应（进程在、socket 返回 000），需**再次 force quit + `open -a Docker`** 才真正恢复
- **遗留**：`trendradar` 仍 Restarting(1) 崩溃循环（日志 `❌ 配置文件缺失`）；`graphiti-falkordb` 当时未出现在容器列表，需核查（Graphiti 依赖）

## [2026-09-20] 🔧 VLM（qwen3-vl:8b）读图连续超时根治 <!-- project: github.com/limuran117-coder/Scenic-Area-Marketing-CN -->

- **根因 1（模型特性）**：`qwen3-vl:8b` 是 **thinking 模型** —— 输出进 `thinking` 字段、`response` 为空；必须烧完 **~835 个 thinking token** 才产出 content。token 预算被截断 → 正文恒为空
- **根因 2（成本叠加，真凶）**：单图 ≈ **92s**（prompt_eval ~43s @1671x2014 + eval ~48s @14.3 tok/s）；`view_image` 每次传 **3 张图**（`douyin_kw_*_tab1/2/3.png`）→ 3×92=276s + 冷加载 13s ≈ **289s，正好卡在 300s 超时线上**
- ❌ `think:false`（/api/generate 与 /api/chat）与 Qwen3 `/no_think` 软开关**均无效**，无法关掉 thinking
- ✅ **修复**：`tools.media.models[0].timeoutSeconds` 300 → **900**（配置 `~/.openclaw/openclaw.json`，`imageModel.primary = ollama/qwen3-vl:8b`）；原配置已备份
- **未做的可选优化**：①送图前下采样（直降 prompt_eval，最大杠杆）②ollama `keep_alive` 常驻免冷启动 13s
- 结论：模型本身**能用**（`done_reason: stop`，686 tokens 正文完整），问题全在预算与时延，不是模型坏
